# Introduction to Middleware
Промежуточное программное обеспечение (MIDDLEWARE) - ЭТО одна ИЗ основных концепций Express.js, платформы веб-приложений для Node.js. Функции промежуточного программного обеспечения - это функции, которые имеют доступ к объекту запроса (req), объекту ответа (res) и следующей функции промежуточного программного обеспечения в цикле запроса-ответа приложения. Промежуточное программное обеспечение может выполнять множество задач, таких как выполнение кода, внесение изменений в объекты запроса и ответа, завершение цикла запрос-ответ и вызов следующей функции промежуточного программного обеспечения в стеке.

Функции промежуточного программного обеспечения являются сердцем приложений Express. Они обеспечивают надежный механизм обработки HTTP-запросов и ответов, позволяя разработчикам создавать сложные и многофункциональные веб-приложения. Понимание того, как работает промежуточное программное обеспечение и как его эффективно использовать, имеет решающее значение для любого разработчика, работающего с Express.

Концепция промежуточного программного обеспечения возникла в результате интеграции корпоративных приложений, где промежуточное программное обеспечение выступает в качестве связующего звена для соединения различных систем. В контексте Express.js функции промежуточного программного обеспечения размещаются в стеке и выполняются последовательно, что позволяет эффективно управлять сложными рабочим процессами. Интересный факт: Термин "промежуточное программное обеспечение" был впервые введен в обиход в 1960-х годах для описания программного обеспечения, которое связывало два отдельных приложения или процесса. В современной веб -разработке промежуточное программное обеспечение стало важным компонентом обработки запросов и ответов, создание приложений, более модульных и удобных в обслуживании.

## What is Middleware?
Программное ОБЕСПЕЧЕНИЕ MIDDLEWARE - ЭТО, по сути, набор функций, которые ***выполняются последовательно для каждого запроса***, поступающего на сервер. Каждая функция промежуточного программного обеспечения может выполнять операции с объектами запроса и ответа и либо передавать управление следующей функции промежуточного программного обеспечения с помощью функции next(), либо завершать цикл запрос-ответ, отправляя ответ клиенту.

## Key Characteristics of Middleware

#### Chain of Functions 
Функции промежуточного программного обеспечения образуют цепочку операций, в которой каждая функция выполняет определенную задачу, а затем передает управление следующей функции в последовательности.

#### Access to Request and Response Objects
Функции промежуточного программного обеспечения имеют доступ к объектам запроса (req) и ответа (res), что позволяет им считывать данные из этих объектов и изменять их по мере необходимости.

#### Control Flow
Функции промежуточного программного обеспечения могут управлять ходом цикла запрос-ответ. Вызывая next(), они передают управление следующей функции промежуточного программного обеспечения. Если они не вызывают next(), цикл запрос-ответ завершается.

#### Order Matters 
Важен порядок, в котором определяются функции промежуточного программного обеспечения. Они выполняются в том порядке, в котором они добавляются в приложение.
