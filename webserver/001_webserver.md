# Simple Web Server
Создание ПРОСТОГО ВЕБ-сервера в Node.js - важный шаг к пониманию того, как работают серверные приложения. Node.js Встроенный http-модуль предоставляет все необходимые функциональные возможности для настройки базового веб-сервера. В этом разделе мы расскажем вам о процессе создания простого веб-сервера, подробно объяснив каждую его часть.

#### Step 1: Import the HTTP Module
Сначала вам нужно импортировать модуль http. Этот модуль предоставляет метод createServer, который будет использоваться для создания веб-сервера.

```const http = require ('http');```

#### Step 2: Create the Server
Используйте метод createServer для создания сервера. Этот метод использует функцию обратного вызова, которая будет выполняться каждый раз, когда сервер получает запрос. Функция обратного вызова имеет два параметра: req (объект запроса) и res (объект ответа).

#### Step 3: Listen on a Port
Сообщите серверу, чтобы он прослушивал определенный порт. Обычно для разработки используются порты 3000, 8080 и 5000.

```const PORT = 3000;```

Создание простого веб-сервера может показаться простым делом, но это фундаментальный навык, который способствовал развитию Интернета. Знаете ли вы, что самый первый веб-сервер был создан Тимом Бернерсом-Ли в 1990 году на компьютере NeXT? Этот сервер, наряду с первым веб-браузером, проложил путь для Всемирной паутины. Современные веб-серверы, подобные тем, которые вы создаете с помощью Node.js, могут обрабатывать миллионы запросов в секунду благодаря достижениям в области неблокирующего ввода-вывода и событийно-ориентированного программирования.
